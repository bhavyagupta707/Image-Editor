# 🖼️ NumPy Image Editor

A simple command-line image editor built using **Python**, **NumPy**, and **OpenCV**. This project allows users to load, edit, preview, and save images using common image processing operations.

## 🚀 Features

* 📂 Load an image
* 👀 Display the image
* ⚫ Convert to Grayscale
* 🎨 Create a Negative image
* ☀️ Increase Brightness
* 🔄 Rotate image by 90°
* ↔️ Flip image horizontally
* 🌫️ Apply Gaussian Blur
* ✨ Detect Edges using Canny Edge Detection
* 💾 Save the edited image

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/numpy-image-editor.git
```

### 2. Move into the project folder

```bash
cd numpy-image-editor
```

### 3. Install the required libraries

```bash
pip install opencv-python numpy
```

---

## ▶️ How to Run

Run the Python file:

```bash
python image_editor.py
```

You will see the following menu:

```text
===== NumPy Image Editor =====
1. Load Image
2. Show Image
3. Grayscale
4. Negative
5. Increase Brightness
6. Rotate 90°
7. Flip Horizontal
8. Blur
9. Edge Detection
10. Save Image
11. Exit
```

Choose an option by entering its corresponding number.
